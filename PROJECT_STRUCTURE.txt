🎯 PRIMEIROS PASSOS
═══════════════════════════════════════════════════════════════

1️⃣  CONFIGURAR DADOS
   └─ Editar: data/projects.json
   └─ Adicionar seus projetos no formato JSON
   └─ Máximo: 1 hora (4 projetos)

2️⃣  TESTAR LOCALMENTE
    └─ Abrir Terminal na pasta
    └─ Executar: npm start
    └─ Acessar: http://localhost:8000
    └─ Verificar: Navbar, Hero, Skills, Projects, Footer

3️⃣  CUSTOMIZAR VISUAL (OPCIONAL)
    └─ Editar: css/styles.css
    └─ Mudar variáveis CSS (:root)
    └─ Recriar: npm run build:css

4️⃣  FAZER DEPLOY
   └─ Criar ou renomear repo: portfolio no GitHub
   └─ Fazer push dos arquivos
   └─ Ativar GitHub Pages em Settings
   └─ Acessar: https://jonnxpr.github.io/portfolio/
