🆘 TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════

PROBLEMA: Site não abre em localhost:8000
SOLUÇÃO: 
  - Verifique se Python está instalado: python --version
  - Tente: python3 -m http.server 8000
  - Verifique a porta (8000 pode estar em uso)

PROBLEMA: CSS não está carregando
SOLUÇÃO:
  - F12 → Console para ver erros
  - Ctrl+Shift+Delete para limpar cache
  - Verifique path: css/styles.min.css

PROBLEMA: Projetos não aparecem
SOLUÇÃO:
  - Verifique JSON syntax em projects.json
  - F12 → Console para ver erros
  - Verifique se arquivo está em data/projects.json

PROBLEMA: GitHub Pages não funciona
SOLUÇÃO:
  - Verifique se repo é public
  - Settings → Pages → Deploy from branch
  - Aguarde 2 minutos
  - Ctrl+Shift+Delete para limpar cache
