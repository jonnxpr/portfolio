## 🎮 COMO COMEÇAR (5 MINUTOS)

### 1. Testar Localmente
```bash
# Abra Terminal/PowerShell na pasta Portifolio
python -m http.server 8000

# Abra navegador em:
http://localhost:8000
```

### 2. Editar Seus Projetos
```
Arquivo: data/projects.json
Formato: Array JSON com 4 campos principais
├─ title: Nome do projeto
├─ description: Descrição
├─ technologies: Array de tecnologias
└─ links: { github, demo }
```

### 3. Customizar Visual (Opcional)
```
Arquivo: css/styles.css
Seção: :root
Edite: Cores, fonts, spacing
Salve: Regenere styles.min.css
```

### 4. Fazer Deploy no GitHub
```
1. Criar repo: jonnxpr.github.io
2. git push dos arquivos
3. Ativar GitHub Pages em Settings
4. Acessar: https://jonnxpr.github.io
```

## 🎨 CUSTOMIZAÇÕES COMUNS

### 1. Mudar Cor Neon Principal
```css
/* Em css/styles.css no :root */
--color-neon-cian: #00d9ff;      /* Para outra cor */
--color-neon-magenta: #ff00ff;   /* E aqui também */
```

### 2. Adicionar Mais Projetos
```json
// Em data/projects.json, copie um card e edite:
{
  "id": 5,
  "title": "Seu Novo Projeto",
  "description": "Descrição aqui",
  "technologies": ["Tech1", "Tech2"],
  "icon": "<i class='fas fa-icon'></i>",
  "links": { "github": "seu-link" }
}
```

### 3. Mudar Tipografia
```css
/* Em css/styles.css */
--font-main: 'Sua Nova Fonte', sans-serif;
--font-mono: 'Outra Fonte', monospace;
```

## 📞 SUPORTE RÁPIDO

### Dúvida: Como adicionar foto de perfil?
**Resposta:** Adicione em `<section class="hero">` após `<div class="hero__content">`:
```html
<img src="assets/seu-foto.jpg" alt="Sua foto" style="width: 200px; border-radius: 50%; border: 2px solid #00d9ff;">
```

### Dúvida: Como mudar nome do portfólio?
**Resposta:** Edite em `index.html`:
- `<title>` tag
- `meta name="description"`
- Texto em `<h1>` da hero section

### Dúvida: GitHub Pages não está funcionando?
**Resposta:** Verifique em Settings → Pages:
- Source: "Deploy from a branch"
- Branch: "main"
- Folder: "/ (root)"
